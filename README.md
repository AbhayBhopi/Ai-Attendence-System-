# AI Facial Recognition Attendance System

An automated AI-powered attendance tracking system combining real-time facial recognition, modern landing presentation page, and backend management API.

## 📁 Repository Structure
- **`app/`**: Main Application Engine (Python, OpenCV, Face Recognition & PyTorch pipeline)
- **`landing/`**: Presentation Landing Page (HTML5, Tailwind CSS, JavaScript)

## 🚀 Environment Configuration
Create a `.env` file inside `app/` based on `.env.example`:
```env
DATABASE_URL=your_database_url
SECRET_KEY=your_secret_key
API_KEY=your_api_key
```

## 🛠 Setup & Installation
```bash
# Application Engine
cd app
pip install -r requirements.txt

# Landing Page
cd ../landing
```
